# Cross-page CSS class collisions — shrinking backlog
#
# Each class below is defined UNSCOPED (a bare `.foo { }` rule) inside the
# page-local <style> block of two or more templates. Whichever page you are on
# wins, so the same class name means different things in different places. That
# is the mechanism by which this UI drifts apart.
#
# tests/test_frontend_consistency.py fails on any collision NOT listed here, so
# new ones cannot be introduced. Entries here are pre-existing and are meant to
# be removed over time by either:
#   * scoping the rule under the page's own wrapper (e.g. `.gps-page .gps-chip`), or
#   * promoting the shared design into static/css/styles.css and expressing the
#     per-page difference as a modifier class.
#
# Do NOT add to this file to silence a collision you just introduced.
#
# The `.gps-*` block is the largest cluster: the GPS live panel was copy-pasted
# across the GPS dashboard, Hardware Settings and System Health, and the three
# copies have since diverged (no two rules are byte-identical).
