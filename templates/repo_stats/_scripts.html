{# Repository Statistics — Chart.js rendering. Data arrives via the #repoStatsData JSON block so no server values are interpolated into JS. Theme changes are applied through Chart.defaults and the dataset objects only. Never assign into `chart.options.*` — in Chart.js v3+ that is a resolved-options proxy, and writing a value read back out of it (the `opts.plugins.legend.labels = opts.plugins.legend.labels || {}` idiom) builds a self-referential proxy chain that blows the stack on the next update. #}
