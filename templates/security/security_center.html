Host-Firewall Enforcement (fail2ban)

There is one ban list — the Banned IPs tab. fail2ban is an optional firewall enforcer for it: when enabled, every application ban (manual or automatic) is also dropped at the host firewall, before traffic reaches the web app. You still add, remove, and review web bans on the Banned IPs tab — nothing to manage twice here.
