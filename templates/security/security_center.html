fail2ban Integration

Malicious and failed login attempts are written to the security log in a fail2ban-parseable format. Deploy the configuration below on the host to have fail2ban automatically ban attacking IPs at the firewall level (in addition to the application-level bans managed on the Banned IPs tab).

1. Jail Configuration /etc/fail2ban/jail.local
2. Filter Configuration /etc/fail2ban/filter.d/eas-station-malicious.conf
