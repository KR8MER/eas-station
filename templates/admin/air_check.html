An air-check receiver is an SDR tuned to this station's own transmitter. Every alert the station sends (automatic, relayed, manual, RWT or resend) opens an air-check with the exact SAME header that went out. When the air-check receiver decodes that header back off the air, the check is verified — or flagged as a mismatch if any header field differs. If nothing is heard by the deadline, the check is missed and an error is logged and emailed to the compliance contacts. Decodes from air-check receivers are never relayed.
