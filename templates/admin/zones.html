NOAA Zone Catalog

Manage the NOAA National Weather Service zone catalog database

Where to get zone catalog files (NOAA/NWS):
  • Public forecast zones (land — z_*.dbf): weather.gov/gis/PublicZones
  • Marine zones (coastal, Great Lakes, offshore — mz*.dbf): weather.gov/gis/MarineZones
  • Fire-weather zones (fz_*.dbf): weather.gov/gis/FireZones
  • NWR partial counties (subdivisions — cs*.dbf): weather.gov/gis/NWRPartialCounties
Each link goes to the official NOAA landing page; download the ZIP, extract the .dbf, and upload it below. Headless installs can run python tools/download_nws_gis_data.py (use --zones, --marine, or --partial to fetch one family at a time). See NWS_ZONE_CATALOG.md for the full refresh procedure, schema, and validator behavior.
