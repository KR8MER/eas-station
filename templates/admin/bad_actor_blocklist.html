    About This Blocklist

    A daily timer (bad-actors-update.timer) refreshes the Spamhaus DROP/EDROP feed automatically. The list is enforced by nginx before a request ever reaches the application, so blocked traffic never shows up in the app's own logs.

    Local additions live in config/bad-actors-local.conf, checked into git so they survive deployments. The allowlist above is for bypassing the blocklist entirely (e.g. a monitoring service or VPN egress IP that happens to appear on Spamhaus's list).
