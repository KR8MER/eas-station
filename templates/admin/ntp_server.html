How It Works

chrony already keeps this host's own clock synced — normally purely as a client. This page lets it also answer NTP queries from devices on subnets you choose, so they can sync to it instead of (or as a fallback to) the public internet.

  1. List the subnet(s) that should be allowed to query this host (your LAN, a VPN range, etc.).
  2. Enable and click Apply — this writes a chrony config fragment, restarts chrony, and opens the matching firewall port for exactly those subnets.
  3. Point your LAN devices' NTP client at this host's address.

Scope It Carefully

  • Never allow 0.0.0.0/0 or ::/0 — an open NTP responder reachable from the whole internet is a known amplification-DoS vector.
  • On a cloud VPS, the box's own public interface subnet is not your LAN — don't use the "for reference" suggestion(s) above blindly.
  • Disabling clears both the chrony config and every firewall rule this feature added — nothing lingers.

Quick Reference

# Current sync sources
chronyc sources
# Clients that have queried this host
chronyc clients
