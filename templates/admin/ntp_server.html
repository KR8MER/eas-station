How It Works

chrony already keeps this host's own clock synced — normally purely as a client. This page's Firewall settings let it also answer NTP queries from devices on subnets you choose, so they can sync to it instead of (or as a fallback to) the public internet.

  1. Go to Settings → Firewall and list the subnet(s) that should be allowed to query this host.
  2. Apply — this writes a chrony config fragment, restarts chrony, and opens the matching firewall port for exactly those subnets.
  3. Point your LAN devices' NTP client at this host's address.

Quick Reference

# Current sync sources
chronyc sources
# Clients that have queried this host
chronyc clients
# View chrony log
journalctl -u chrony -f
