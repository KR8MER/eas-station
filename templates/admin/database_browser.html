How access is protected

pgweb is a third-party tool for browsing and querying a PostgreSQL database directly — useful for ad-hoc troubleshooting, but it has no login of its own. Whoever can reach its port gets full read/write SQL access to every table in this system, including administrator accounts.

pgweb itself only listens on 127.0.0.1, so it can never be reached directly over the network. The only way in is through nginx on port 8081, which checks with this application first — the same sign-in and system.configure permission this page required to load — before it will proxy the connection through.
