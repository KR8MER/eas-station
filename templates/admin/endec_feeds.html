Feed Configuration

What is this? Each feed opens a TCP port and pushes a copy of every alert event (sent, matched, not-matched, duplicate) to all connected clients, formatted like a Sage Digital ENDEC's serial device ports. Connect a character generator, newsroom system, or a simple nc <host> <port> to consume the stream. See the protocol reference.
Master switch. When disabled, no TCP listeners run regardless of the rows below.

Format Reference

Generic CGEN — <STX><sev><text><ETX>. Severity 1/2/3 sets the display colour. For character generators.

News Feed — text framed by <ENDECSTART>…<ENDECEND> for newsroom/wire software.

Decoder — status lines local: / match: / nomatch: / dup: plus the ZCZC header and plain-language text. Great for monitoring/observability.

Encoder — raw EAS byte mirror of outgoing alerts (0xAB preamble + ZCZC ×3 + NNNN ×3). External decoders / capture.

A change here hot-reloads the eas-station-endec-feeds service — no restart needed.
