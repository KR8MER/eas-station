MDC1200 (Motorola Selective Calling) transmits a 1200-baud FFSK packet (mark = 1200 Hz, space = 1800 Hz) carrying this station's Unit ID and an op-code. Receiving Motorola radios display the unit ID and execute the op-code (PTT-ID, Emergency, etc.). Single-packet ops (PTT-ID, Emergency, Request to Talk, Remote Monitor) are ~173 ms; double-packet ops (Call Alert, Selective Call) carry a target unit ID in a second info block and are ~267 ms. Signal-duration field is ignored. Verify on the bench with a dedicated MDC1200 decoder such as mdc-decoder (decodes a WAV directly) before going on the air — note that mainline multimon-ng does not include an MDC demodulator.
16-bit subscriber ID (1–65535 decimal, or 0x0001–0xFFFF hex). Motorola CPS often shows unit IDs in 4-digit hex.
Pick a preset, or choose Custom to set raw bytes. For Call Alert and Selective Call the Unit ID above is the target radio's ID. Leave this on PTT-ID Pre to bookend the broadcast — see the note below.
Bookend pair active. Both the Pre- and Post-Alert Signals are set to MDC1200 with op-code PTT-ID Pre, so the broadcast is automatically bookended: PTT-ID Pre (op 0x01) is sent before the alert and PTT-ID Post (op 0x00) after it. You don't pick both manually — the post-side packet is substituted for you. Choosing any other op-code sends that same op-code on both ends instead.
