Support EAS Station™

EAS Station™ is free and open-source software, built and maintained in the open. If it’s useful to you — in the lab, the shack, or the classroom — a one-time or monthly contribution keeps development moving.

Support on Ko-fi

Where Your Support Goes

Donations fund the parts of the project that aren’t free.

  • Hardware for testing. Raspberry Pi boards, SDR receivers, GPIO and display peripherals used to validate releases on real bare metal.
  • Development time. New features, bug fixes, security updates, and keeping dependencies current.
  • Documentation & support. Guides, the theory-of-operation material, and answering questions from operators and researchers.

Other Ways to Help

Not everything costs money — these help just as much.

  • Star the repository. Visibility on GitHub helps the project reach more people.
  • Report bugs & ideas. Open an issue when something breaks or could be better.
  • Contribute code or docs. See the Contributing Guide to get started.
