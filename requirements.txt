# NEXRAD Level II radar decoding for the weather-alert radar overlay
# (app_utils/image_export/radar_level2.py). Level II is the raw per-site
# volume scan (~250m gate, ~0.5deg azimuth resolution) -- the fine-grained
# look public radar apps show near a site -- vs. the Level III national
# mosaic (~1km, WMS-T from Iowa Environmental Mesonet) used as the
# fallback when no Level II volume is available (site down, alert far
# outside all site coverage, etc.). Pulls in a heavy transitive chain
# (xarray, dask, pandas, netCDF4, h5py, shapely on top of the numpy/
# scipy/pyproj/matplotlib/cartopy already required) -- a real departure
# from this project's normal "keep it minimal" posture, accepted here
# because there is no lighter-weight NEXRAD Archive II decoder in the
# Python ecosystem. `arm_pyart` has no prebuilt ARM wheel (piwheels
# covers its dependencies but not the package itself) -- expect a ~5-6
# minute from-source build the first time, one-time cost.
arm_pyart==2.2.5  # NEXRAD Archive II decode; RadarMapDisplay.plot_ppi_map renders each gate's true polar footprint, no interpolation (PyPI name; imports as `pyart`)
boto3==1.43.56  # Unencrypted, anonymous read access to NOAA's public Level II archive on AWS Open Data (no credentials needed)
cartopy==0.25.0  # Geographic (Web Mercator) projection for plot_ppi_map, matching the OSM basemap tiles it composites onto
cmweather==0.3.2  # Registers the 'NWSRef' reflectivity colormap (the standard ~15-band NWS scale most radar apps use, not a hand-rolled ramp)
matplotlib==3.11.1  # plot_ppi_map's rendering backend (Agg, headless) -- pcolormesh draws each gate's true polar footprint
